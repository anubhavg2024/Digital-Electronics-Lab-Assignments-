
# A1 – Discussion

The given five-variable Boolean function was simplified using Karnaugh maps.

The original function:

\[
F(A,B,C,D,E)= Sigma m(0,1,4,5,16,17,20,21,26,27,30,31)
\]

The simplified expression is:

\[
\F=B'D'+ABD
\]

## Observations

- The function was reduced from 12 minterms to 2 terms.
- Variables C and E were eliminated.
- The simplified circuit requires fewer logic gates.
- Both expressions produce identical outputs for all 32 input combinations.

## Conclusion

Karnaugh map simplification reduces circuit complexity while preserving the original Boolean function. The simplified circuit is more efficient and easier to implement.
